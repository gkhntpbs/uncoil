## Behavior

- Launch context and MCP initialization instructions keep ordinary work in the current session. Uncoil tools are used for managed state; delegation requires user or project instructions. Authorized coordination uses existing sessions, idempotency keys, event waits and child reports.
- `request_permission` opens a separate native approval window, waits up to 120 seconds by default (0–300 configurable per call), and returns the decision. A pending result may be awaited again with the same key and target.
- Approval supports once or until revoked. Closing denies. Retry does not reopen a denial; Settings → Permissions can remove it. Expired and consumed requests can be requested again. Notification actions cannot grant an already decided or expired request.
- Computer handlers honor caller-specific permission records without changing static capabilities or child inheritance.
- Child reports return an error when they cannot be persisted.
