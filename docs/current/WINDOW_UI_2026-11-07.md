# Edge window and approval UI — 2026-11-07

Local work on `edge`; no push or release publication.

## Changes

- Approval panels are always 520 × 420 points. They use a frameless dark surface, a subtle border, fixed typography and button sizes, and an explicit blue Allow Once action. Caller/target labels are bounded and expose full names through help text. Permission semantics are unchanged.
- A native titlebar interaction view fills the current screen's visible frame on double-click and restores the previous frame on the next double-click. It excludes native window buttons and titlebar accessories, supports dragging, and never calls fullscreen APIs.
- Project folder labels route mouse events to the outline view. Clicking anywhere on the row toggles expansion even when the row is already selected. The chevron is decorative; native drag/reorder remains available.
